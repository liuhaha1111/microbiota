### 基础医疗材质与背景色（非语义中性色）
- **全局 3D 背景**：纯色低反射暗场灰黑 `#0F141C`（无径向渐变、无发光光晕）。
- **健康肠壁与上皮组织**：柔和次表面散射感（Subsurface Scattering 近似 PBR，`roughness: 0.55`, `clearcoat: 0.25`, `sheen: 0.35`）暖珊瑚肌理色 `#C87A72`（暗部阴影 `#6E3835`）。
- **受损/炎症肠壁组织**：充血水肿暗红褐色 `#A84A42`，表面粗糙度升高（`roughness: 0.78`），伴随黏液层透明薄膜（`#8CB8BE`, `transmission: 0.65`）局部缺失。

3. **尺度切换逻辑**

   - `浮标 3`（锚定底部收集囊）：**核心产丁酸菌有效载荷（演示基线）** · 证据等级：专家共识

### 关键状态图 3：定植与屏障修复 —— 黏液层与上皮隐窝微观下钻（对应阶段 4 及微观 4.1–4.4）
*(离线矢量效果图文件：`/public/mockups/state3_micro_barrier.svg`)*

1. **相机参数（微观组织学剖面视角 · Microscopic Histological Cutaway）**
   - **视角类型**：肠黏膜双层黏液屏障 + 隐窝（Crypt of Lieberkühn）+ 单层柱状上皮 + 固有层免疫微环境正交斜切视角
   - **位置（Position）**：`[x: 0.6, y: 0.4, z: 2.35]`（在微观下钻 4 子步间还会沿 X/Y 轴做微距聚焦平移）
   - **朝向目标（Target / LookAt）**：`[x: 0.0, y: -0.15, z: 0.0]`
   - **视场角（FOV）**：`32°`（显微长焦透视，突出组织层次纵深感）
2. **3D 主体构成**
   - **实体网格（Meshes）**：
     - **底层（固有层 Lamina Propria）**：半透明结缔组织基质与毛细血管床，内含树突状细胞（DCs，星状多分支网格）与调节性 T 细胞（Treg，`#2B9EB3` 柔光球体）/ Th17 细胞（`#E06D3B`）。
     - **中层（单层柱状上皮与隐窝）**：24 个排列成弧形隐窝阵列的柱状上皮细胞与杯状细胞（Goblet Cells，分泌黏蛋白颗粒），细胞间带有显式建模的**紧密连接蛋白带（ZO-1 / Occludin 桥接环）**。当处于失衡态时，细胞间隙变宽、桥接环断裂（琥珀色 `#E06D3B` 警示）；修复态时桥接环闭合（青绿蓝 `#2B9EB3`）。
     - **表层（双层黏液屏障）**：内层致密无菌黏液层（半透明高折射凝胶层）+ 外层松散黏液层（纤维状糖蛋白网架结构）。
   - **粒子系统（Particle Systems）**：
     - 供体共生菌群（`#2B9EB3` 哑光杆菌与双歧形态，`InstancedMesh`）锚定于外黏液层并分泌代谢颗粒；
     - 机会致病菌（`#E06D3B` 梭状芽孢杆菌形态）在次级胆汁酸与生态位竞争下脱离黏液层；
     - 代谢产物微粒（丁酸盐 SCFAs 与吲哚衍生物，细小柔和青色微粒）从外黏液层向柱状上皮细胞顶膜扩散。
   - **流线（Streamlines）**：
     - 实线流线（`#2B9EB3`）：膳食纤维 → 产丁酸菌发酵 → 丁酸盐进入上皮细胞维持生理性低氧；
     - 虚线流线（`#9488B0` 岩紫灰）：丁酸盐/色氨酸代谢物跨越上皮基底部激活固有层 DC/Treg 的免疫信号通路（显式标注为「机制推测/低证据」虚线流）。
3. **尺度切换（宏观 ↔ 微观过渡设计）**
   - **进入微观（Macro → Micro Transition）**：当用户从阶段 3 进入阶段 4（或点击肠壁高亮微区放大镜热区）时，触发 `800ms` 连续无级缩放过渡：
     1. 相机向结肠内壁半月襞特定微区（带 `44×44px` 聚焦环标识）推进，FOV 从 `40°` 收窄至 `32°`；
     2. 宏观肠段网格通过透明度平滑淡出（Opacity `1.0 → 0.08` 保留轮廓环境参照），同时微观组织学多层网格（外黏液层 → 内黏液层 → 柱状上皮与紧密连接 → 固有层）从聚焦中心由微缩态平滑插值展开至标准比例；
     3. 3D 视口顶部中央浮现 **「微观机制 4 步下钻控制器」**：`[ 4.1 黏附 ] → [ 4.2 定植 ] → [ 4.3 代谢 ] → [ 4.4 免疫互作 ]`（每个按钮高度 `44px`）。
4. **微观 4 子步各自的视觉焦点与 2D 浮标切换**
   - **4.1 黏附**：相机聚焦外黏液层顶面；高亮共生菌黏附素与 MUC2 糖链锚定；浮标显示「MUC2 外黏液层物理锚定（机制推测）」。
