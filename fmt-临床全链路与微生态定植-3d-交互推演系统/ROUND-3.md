## 3. 本轮修改内容（只改「交互直觉」）

1. **全阶段 3D 实体网格直接射线拾取与悬停提示（`src/components/FmtThreeStage.tsx` `pickableMeshes`）**：
   - 将一级/二级滤膜、底部菌群收集舱、内镜导管、肠溶胶囊、结肠半月襞、外松散黏液层、内致密黏液层、柱状上皮/杯状细胞、ZO-1 紧密连接桥、固有层 Treg 与 Th17 细胞全部注册入 `pickableMeshes`（带 16Hz 节流 `pointermove` 检测）。
   - 鼠标悬停或触控点按上述 3D 结构时，视口顶部即刻浮现 `👆 [结构名称与点击作用提示]`，点击直接展开并高亮对应的 2D 锚定浮标机制说明（点击结肠袋微区则直接下钻至阶段 4）。
2. **30 秒极速闭环操作引导（`src/App.tsx`）**：
   - 在右侧阶段专属控件卡片底部增加顺手的 `← 上一阶段` / `下一阶段 →` 按钮（热区 `≥ 44px`），使操作者在调完本阶段控件后无需大幅移动视线即可推进全链路；
   - 在右侧常驻三读数标题栏旁增加紧凑型「高多样性 / 常规供体 / 抗生素暴露」三情景快速对比按钮组，任何医生无需阅读说明书即可在 **20–25 秒内**独立完成五阶段浏览 + 微观下钻 + 抗生素失败模式对比。
